# WarLords · 种族战役2复刻

基于用户提供的《种族战役2完善版》素材和规则，使用 HTML Canvas 与 JavaScript 实现的浏览器版本。当前为 **0.8.0：双人共同征服、混合种族守军与联机攻城**。首次提交保留了可玩的 0.6.3 基线。

## 运行

Windows 可双击根目录的 `开始战役.cmd`，打开 `http://127.0.0.1:18644/index.html`；同一服务的 `coop.html` 是合作入口。保持启动窗口开启。仅玩离线单人也可运行 `种族战役2复刻/开始游戏.exe`（独立端口 18645，无需 Node）。

跨平台需要 Node.js 20 或更新版本。仓库已附带合作服务依赖，无需安装 npm 包。命令行默认端口仍为 18643，可用环境变量 `COOP_PORT` 覆盖：

```sh
node 种族战役2复刻/coop-local-server.cjs
```

- 单人战役 / 野战：<http://127.0.0.1:18643/index.html>
- 双人合作：<http://127.0.0.1:18643/coop.html>
- 合作测试：创建房间后，将邀请链接在另一浏览器页面打开并加入，双方准备后开战。

本轮本地测试服务：`http://127.0.0.1:18646/coop.html`。此临时端口用于 0.8 验证；公网尚未更新。启动已有端口时，请先关闭旧版本地服务再启动新版，前后端需保持同一版本。

## 当前内容

- 九个种族、原表 0–47 号共 48 种单位；每族至少两种独有战斗兵、各族云梯兵和攻城器械。巨怪属于山岭巨魔，巨妖属于恶魔。
- 单人原作风格选族：三名士兵预览、左右切换民族、种族说明。
- 原作 28 个地区、领土相邻关系、驻军和城堡标记；从本族领土出发，逐步征服大陆。
- 初始 500 黄金和四种基础兵（南方兽人为掷斧者替代弓箭手），关前和每关结算后进入原作风格商店。军队最多十种，可购买、升级和出售非基础兵。
- 城堡关累计 7500 攻城进度；云梯搭好后，同路步兵可攀城。普通步兵破门、投石器械与攻城锤均可奏效。守军突破单独扣防线，25 次突破或 5 分钟超时则防守方获胜。
- 战役自动保存、暂停续战、战役导入导出；胜利奖励只发放一次，失败可整备后重试。
- 骑兵、投掷兵、游侠、刺客、巨人及攻城器械的原图动画与投射物；部分兵种升阶、法术与特殊动作。
- 双人共同征服 28 地区：从共同据点出发，选接壤地区，双方准备后野战/攻城，各自购买和升级；守军持续每排八人出兵，逐步混用最多三个种族的特色兵。经典三关试炼也保留。
- 手机横屏点头像选兵、点路线出兵，竖屏保留触控按钮。
- iPhone 主屏幕网页 App 入口、图片载入进度及部署缓存配置。

主菜单“单人战役”开始新征程，“继续战役”恢复进度；“快速野战”保留自由选兵测试。新战役会覆盖浏览器内的旧战役，可先导出文件备份。联机和单人战役的进度相互独立。

这仍是复刻进行中的版本：高阶法术只开放已有光球，其他法术在商店标注未开放；骑兵下马、部分受击/弹道效果、种族被动与原作精细 AI 仍需校准。征服地图暂不包含敌方回合反攻；合作征服进度目前仅保留在房间内存中，服务器重启或房间结束会丢失；尚无长期存档入口。整备闲置一小时或断线超过 30 秒会清理房间，活跃战斗不再按创建时间满一小时强制结束。

## 修改内容

- `种族战役2复刻/balance.js`：生命、速度、准备时间、攻击距离、价格。
- `种族战役2复刻/campaign-data.js`：28 个关卡的名称、相邻地区、敌军、场景、奖励、城堡标记。
- `种族战役2复刻/campaign.js`：初始资金、征服、结算与存档规则。
- `种族战役2复刻/progression.js`、`engine.js`：商店购买、升级与战斗行为。
- `合作模式预研/levels.json`：经典合作三关波次、通关目标、防线。
- `合作模式预研/coop-conquest.cjs`：合作征服的敌军联盟、特色兵池、波次、攻城与奖励。
- [原创种族预研](原创种族预研.md)：新增种族所需素材、接入方法、工程/美术人日估算。

改动联机战斗规则后，要同步更新客户端与服务端，并更新 `content.js` 中的 `rulesVersion`；不能只替换网页而保留旧的服务器进程。数值修改后应重新开战。

## 目录

- `种族战役2复刻/`：网页、引擎、原画图集、数值与本地服务器。
- `合作模式预研/`：合作关卡规则、房间服务与自动验证。
- `联机预研/`：联机测试与 vendored WebSocket 库。
- `deploy/`：Linux 安装与 Nginx 配置参考；使用前按自己的域名、目录修改。
