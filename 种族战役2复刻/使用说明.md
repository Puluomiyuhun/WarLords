# 种族战役2 · 0.7.0

在仓库根目录双击「开始战役.cmd」，打开单人页面。仅玩离线单人也可双击本目录「开始游戏.exe」，无需 Flash 或 Node.js。保持启动窗口开启，移动游戏时移动整个 WarLords 文件夹。

## 单人战役

1. 主菜单点「单人战役」，左右选择九个民族。
2. 初始 500 黄金、四种基础兵，在原作风格商店买兵或升级。南方兽人用掷斧者替代基础弓箭手。
3. 点「征服地图」，选择相邻的敌方领土出征。蓝色为我方，红色为可进攻目标，城堡标记表示攻城战。
4. 每关结束都可回商店整备。胜利得到黄金和领土，失败可重试，不丢已买部队与升级。军队最多十种，初始四兵不可出售。
5. 「继续战役」恢复自动保存的进度；战斗暂停或地图界面均可导出整个战役。主菜单可导入。新战役覆盖旧战役前可先导出备份。

野战净领先 25 次突破获胜；5 分钟结束时领先方获胜，平分继续。攻城需累计 7500 进度，敌人突破另扣防线；防线耗尽或 5 分钟超时则失败。云梯架好后，同路步兵可攀城；普通步兵可以慢慢破门，攻城器械直接伤害城墙。巨怪属于山岭巨魔，巨妖属于恶魔。

## 操作

玩家一 W/S 选路、A/D 选兵、空格出兵，E 切换特殊蓄力；同机玩家二用方向键、Enter、右 Shift。P/Esc 暂停。买到特殊能力后，双倍充能出兵触发特殊动作；换兵不清空充能。切到后台自动暂停。

手机横屏：点左上头像选兵，点路线直接出兵；竖屏保留按钮。iPhone 可以添加到主屏幕隐藏 Safari 标签栏，游戏内提供指引。手机布局已在桌面浏览器视口中验证，仍需真实 iPhone 实测。

自由试兵：在「选项」选择种族，「野战军备」提供每方 3000 试用黄金，然后点「快速野战」或「双人对战」。这笔钱与战役独立。

双人合作：运行「开始双窗口合作.cmd」，两个浏览器进入同一房间，各自整备并准备。仍为三个持续波次试验关，尚未使用单人征服地图。

Windows 脚本使用 18644 端口，独立单人 exe 使用 18645；手动 Node 命令默认仍为 18643。127.0.0.1 地址只供本机，不能发给手机或异地玩家。
