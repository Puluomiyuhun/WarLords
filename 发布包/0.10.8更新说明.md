# 0.10.8-defense-return

无尽模式现在记录独立的防线值：初始 50，我方每名士兵突破恢复 1 点，敌方每名士兵突破扣除 1 点，上限 50，归零结束。双人共享恢复，单人规则相同。同一帧双方突破按净变化计算；跑步离场阶段不会重复计分，满条时溢出的恢复不会储存。

自适应难度继续统计实际突破事件，但低血量保护按当前防线值判断。进商店、继续战斗和存读档保留防线。旧存档保留更新前的剩余防线，不重复发放历史突破恢复。

保留此前的 35 杀整排出兵、后期无尽难度、攻城器和性能修复。全套 npm test 通过；两个独立浏览器验证双方防线数值及条宽同步经历 30 → 31 → 32 → 50 → 49。

上传本目录的 `install-0.10.8-defense-return.sh` 至服务器 `/opt/warlords2/downloads/`，然后执行：

```bash
bash /opt/warlords2/downloads/install-0.10.8-defense-return.sh
```

脚本运行测试后切换服务，自动备份并在切换失败时回滚。成功标志为 `DEPLOY_OK version=0.10.8-defense-return`。更新将关闭旧房间，两位玩家强制刷新后重新建房。本地准备完成不代表已经部署。
