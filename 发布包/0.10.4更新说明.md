# 0.10.4 合作性能与镰刀旋风修复

尚未部署线上。上传 install-netfix.sh 后执行 bash /opt/warlords2/downloads/install-netfix.sh。安装会备份当前文件，运行专项测试，重启游戏服务并验证健康接口；失败恢复旧文件。成功标记 NET_FIX_OK。双方需要 Ctrl+F5 并重新开房。

- 联机战场改用已有半尺寸图集；无尽样本 205 张图，PNG 解码像素估算从 1536 MiB 降至 384 MiB，文件从约 100 MiB 降至 43 MiB。此为图像像素估算，不代表实测进程内存或显存占用。
- 每个状态包只做一次分路、单位索引和绘制排序；无状态特效的单位不再执行空绘制；最多按 60 Hz 请求绘制，避免高刷新率屏幕重复做多余工作。
- WebSocket 启用有并发上限的压缩；同一状态只序列化一次。发送排队时合并周期性战场状态，只保留最新一个，关键事件及命令确认保持发送。
- 本地 100 单位样本，按每秒 12 包、两个客户端计算，未压缩数据约 4.02 Mbps，独立压缩估算约 0.306 Mbps，不含 TLS/TCP 开销，非公网吞吐测量。
- 原作 DefineSprite_484_镰刀旋风/frame_92/DoAction.as 仅在 GetDistance < 70 时进入 bswipe。复刻错误地无条件跳转，现已恢复原距离条件。贴身时保留原版后撤攻击。

验证：完整 npm test 通过；压缩与无压缩双客户端状态一致、批量更新不积压、旋风双方向与边界距离测试通过。随后渲染调整通过本地 Edge 无头浏览器 200 人同屏检查，无页面错误，截图与测量见同目录。无头结果不能保证玩家设备帧率，需要原设备实战复测。
